# NNNN. Short title in the imperative

- **Status:** proposed
- **Date:** YYYY-MM-DD
- **Deciders:** David / council / tribunal / session <codeword>
- **Tenet invoked:** none, or the tenet this decision turned on

## Context

What is true right now that forces a choice. Written in the present tense of today and
never updated afterwards. Include the numbers, the failure, or the constraint that made
this a decision rather than a preference.

## Options considered

At least two, each with what it costs. One option means this was not a decision.

## Decision

What was chosen, stated plainly.

## Consequences

What this makes easy, what it makes hard, and what it rules out. Name at least one thing
that gets worse.
